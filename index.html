📌 作品介绍

一款面向游戏运营场景的 玩家生命周期数据看板原型，基于 Chart.js 独立搭建，把「用户规模 → 留存 → 付费 → 流失」四大指标体系整合为一屏可视化的运营驾驶舱，帮助运营快速判断产品健康度、定位高危风险并给出干预建议。

① 一屏总览：DAU / 7日留存 / 付费转化率 / ARPPU / 30日流失 五大核心 KPI 卡片 + 环比趋势与行业基准对照
② 转化漏斗：注册 → 次日 → 7日 → 首周付费 → 30日 → 核心活跃，支持本周/上周/上月切换，自动计算各级转化率
③ 流失预警：以「连续未登录 + 未完成任务 + 零付费」三重标签定位高危玩家，按 P0/P1/P2 输出干预优先级与挽回预期
④ 召回实验：5 组 A/B 召回方案对比（召回率 / CPA / 7日留存），组合输出最优策略与单用户成本控制建议
⑤ 指标对标：12 项 KPI 与卡牌品类行业基准逐项对比，用数据支撑「健康 / 需关注」的运营判断

技术实现：HTML / CSS / JavaScript + Chart.js（漏斗图 / 折线图 / 极地图），内置可切换周期与阈值的数据模型，模拟运营周报的取数与呈现流程；体现「把运营指标拆解为可解释、可决策的可视化工具」的数据分析能力。
